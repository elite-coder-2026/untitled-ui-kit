Usage Examples

Basic Notification HTML

<!-- Basic notification structure -->
<div class="notification notification--success">
  <div class="notification__content">
    <div class="notification__title">Success!</div>
    <div class="notification__message">Your changes have been saved.</div>
  </div>
  <button class="notification__close">×</button>
</div>

JavaScript Integration

To make these notifications interactive, you'll need to add JavaScript for:

  • Showing/hiding notifications
  • Auto-dismiss timers
  • Stacking and positioning
  • Animation effects
  • Action button handlers
  • Progress updates

Check the js/notifications.js file for implementation details.
